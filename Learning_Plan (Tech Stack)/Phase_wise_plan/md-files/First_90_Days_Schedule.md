# First 90 Days — Week-by-Week Starter Schedule (v10 on-ramp)

**Covers:** the ~16-week on-ramp from a standing start to your first portfolio capstone — **Phase 0 (fundamentals) → first job applications → Phase 1 (math) → Phase 2 + Capstone 1.** Dates assume a **mid-Aug 2026 start** at an aggressive-but-sustainable pace (~38–42 hrs/wk on working weeks, ~18–20 on consolidation weeks). The **self-tests are the true gates** — if one isn't passed, repeat the week; don't advance on shaky ground.

> How to read this: each row is one week. The two consolidation weeks (6 and 12) are deliberate — **do not skip them**; they're what keep confusing terminology from compounding. Applications start in Week 3 and run as a light background track thereafter (your applied medical-imaging skill already makes you eligible — the learning improves your interview *performance*, not your eligibility).

---

## The daily rhythm (once you're rolling)

- **Weekdays (~3–4 hrs/day):** 1 focused evening block. Once threads start (Week 10), the **first ~45 min is a thread** (rotate T → M → R), then phase work.
- **Weekend (~10–12 hrs/day):** 2–3 blocks with breaks. Heaviest lifting (new hard concepts) goes here, when you're fresh.
- **Every night (~15 min):** update the **living glossary** + clear your **Anki** queue (see the Confusion Buffer one-pager).
- **Confusion Buffer, always on:** intuition-first (visual → rigorous → derive), Feynman-gate each concept, and if stuck >30 min, switch teacher rather than grind.

## The applications sub-track (Weeks 3 → ongoing, ~2 hrs/wk)

1. **Week 3:** refresh CV + LinkedIn (lead with medical-imaging segmentation + production ML; frame CV-beyond-medical honestly as growing). Draft a 1-paragraph "why me for digital biology" narrative.
2. **Weeks 3–8:** apply to **Tier 0** (Qure.ai, SigTuple, GE HealthCare Bengaluru, NVIDIA-India, MSR India). ~3–5 quality applications/week > mass spraying. Track in a simple sheet.
3. **Weeks 9–16:** as Capstone 1 takes shape, add it to your CV/portfolio, request warm referrals, and start Tier-0 interview loops. Treat early loops as **paid calibration** — every rejection is interview-format data.
4. **From Week 16:** Capstone 1 live → strengthen every application; begin stretching toward Google-India and (once Capstone 2 lands ~Jan) Tier 1.

*Reminder (COI): public data and generic methods only; personal hardware/accounts; clear anything public through Lilly's review. Nothing from Lilly or the QpiAI engagement.*

## What "done" looks like at the two gates in this window

- **Phase 0 self-test (Week 3):** explain ~15 fundamentals out loud, plain language, no notes — p-value, CI, CLT, MLE, bias-variance, ROC/AUC vs PR, why L1→sparsity, backprop, BatchNorm. *This is your interview-articulation warm-up — pass it before applying.*
- **Phase 1 self-test (Week 10):** hand-derive backprop for a 2-layer MLP; implement micrograd from memory; explain why BatchNorm helps and what breaks without it; whiteboard scaled-dot-product attention and derive the √dₖ scaling. *Threads only start once you pass — they reinforce a foundation, not a gap.*

If either gate isn't clean, add a repeat/consolidation week. Stretching the timeline a week beats carrying a hole into Phase 2.
